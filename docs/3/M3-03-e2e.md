# М3.3 — E2E (Playwright): login → board → card → drag → AI

Имена из плана → код: login = `RegisterForm` / `LoginForm` + `proxy.ts`; board = `CreateBoardForm`; card = `CreateCardForm`; drag = handle `Move card …` + `PATCH /api/cards/:id`; AI = `SuggestSubtasks` → `POST /api/cards/:id/suggest`.

## Шаг 0 — граница E2E

Живой Chromium бьёт в живой Next + локальный Postgres + Auth.js. Coverage % не цель — critical path. MSW и `vi.mock(actions)` здесь запрещены: это снова M3.1/M3.2.

| Слой | Мок | Что проверяем |
| --- | --- | --- |
| UI → Server Actions / REST / cookie | нет | register/login, create board, add card, persist после reload |
| Postgres, Prisma, Auth.js Credentials, Route Handlers | нет | — |
| GitHub OAuth | нет, не тестируем | нужен реальный GitHub App |
| Vercel AI Gateway | нет в дефолтном прогоне | ключ платный; стрим открывается 200 до ответа модели |
| Suggest без ключа | нет | кнопка → 503 → «AI is not configured. Add AI_GATEWAY_API_KEY.» |
| Suggest список + Add | только `page.route`, если взлетит протокол `useObject` | иначе не пилим test-seam в handler |
| axe / Lighthouse | нет | М3.4 / М3.5 |

Гость `/dashboard` → `/login` — `proxy.ts`, не RTL. Неверный пароль → `?error=credentials`. Register уникального email сам делает `signIn`; отдельный Log in после Sign out закрывает «login» из плана.

Drag: мышь на handle (`data-drag-handle`, 8px), не title. Persist — reload, не только `onDragOver`. Клавиатура / пустая колонка — М3.4, если мышью In Progress нестабильна.

БД: локальный Postgres (`127.0.0.1:5433`), не Neon. `AUTH_SECRET`, `nvm use 24`. App+db в Docker — М4.

Husky / CI тесты не вешаем — это М4.

# М2.9 — AI MVP «Suggest subtasks»: Route Handler как proxy

Сделано:

- Пакеты по доке AI SDK 7, не 6: `ai` `^7.0.93`, `@ai-sdk/react` `^4.0.96`. Zod уже `^4`. `@ai-sdk/openai` не ставили — Gateway встроен в `ai`. Ключ `AI_GATEWAY_API_KEY` только сервер (не `NEXT_PUBLIC_`); `.env.example` + README. Без ключа UI не падает: кнопка есть, ответ — 503 `unavailable`
- Контракт в `src/features/ai-assistant/`: `{ subtasks: { title }[] }`, 3–7 пунктов, title как у карточки (1–200). Клиент шлёт только `cardId` в URL. Title/description для промпта — из БД (`getOwnedCard`), не из body. Промпт: короткие шаги, язык как у title, без нумерации
- `POST /api/cards/[cardId]/suggest` — не Server Action: стрим LLM так не делают, ключ не утекает на клиент. Порядок: `requireApiUser` → 401; нет ключа → 503; `parseIdParam` + `getOwnedCard` → 404 как у остального API (чужой id не светим). Иначе `streamText` + `Output.object` + `createTextStreamResponse` / `toTextStream`, модель `openai/gpt-4o-mini`, `maxDuration = 30`. Body не читаем. Prisma только через `service`. Код `unavailable` в `ApiErrorCode`
- Почему без таблицы Subtask: MVP — список в памяти `useObject`, Add создаёт обычную карточку в ту же колонку (`createCardAction` + optimistic, как ручная форма). Отдельная сущность и чат по доске — М6
- Клиент: `useSuggestSubtasks` → `useObject` на этот URL. Temp / edit — кнопки нет (как Delete/drag). Стрим: «Suggesting…», Stop, пункты дорисовываются. Add по готовому title; повторно тот же индекс не кладём. Add all нет. Ошибки инлайн (`role="alert"`), не `?error=`
- Свой `fetch` у `useObject`: иначе SDK кладёт сырой JSON в `error.message`. `apiErrorFromResponse` + `suggestError`: 401 / 404 / 503 / сеть — одно человеческое сообщение. Stop глотает `AbortError` — ошибки нет. Redis / счётчик в БД не добавляли — rate limit это М5. Потолок стоимости — 3–7 в схеме и промпте

Проверка: `npm run typecheck` + `npm run lint`. Network: `POST /api/cards/:id/suggest`, не api.openai.com с клиента. Ключ в `.env` есть — 503 не ловили. Стрим до модели не дошёл: сначала `GatewayTimeoutError` (`ai-gateway.vercel.sh:443`), потом 403 `customer_verification_required` — Gateway просит карту, чтобы открыть бесплатный кредит (не trial на N дней; покупка кредитов не обязательна). Handler уже отдал 200 (стрим стартует до ответа модели) — список пустой, инлайн-ошибки нет: `useObject` падает только на `!response.ok`. Drag/edit/delete не трогали

Не делали: Zustand, RHF, shadcn, Query на список досок, column CUD через `useOptimistic`, drag колонок, gap-based, тесты, axe/Playwright, `cacheComponents`, таблица Subtask, Redis rate limit, чат по доске, карта/оплата Gateway, маппинг ошибки стрима после HTTP 200
